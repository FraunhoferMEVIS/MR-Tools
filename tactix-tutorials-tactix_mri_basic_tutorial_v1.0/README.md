# MRI Basic Tutorial

## Description
An educational repository dedicated to the fundamental principles of Magnetic Resonance Imaging (MRI). This project includes a Bloch Simulator, which is an interactive visualization tool that demonstrates the core concepts of the field.

## Installation
To run this project, ensure you have the required dependencies installed. The application is built using Python and requires Streamlit for interactive visualization.

### Prerequisites
Make sure you have the following installed:
- numpy
- matplotlib
- pyarrow
- streamlit==1.54

You can install the dependencies using:
```bash
pip install numpy matplotlib pyarrow streamlit==1.54
```

## Usage
This project uses Streamlit to create an interactive tutorial on background information to be used in conjunction with the Bloch simulator. 

### Running the Application
To start the application, navigate to the project directory and run:
```bash
python -m streamlit run Bloch_Simulator_streamlit.py

```
This will launch a web-based interface which lets you explore the contents of the tutorial.
